# Architecture Decision Records (ADR)

Esta pasta registra decisões arquiteturais relevantes do projeto.

Cada ADR documenta:

- contexto;
- problema;
- decisão;
- consequências;
- componentes impactados;
- status da implementação.

As ADRs servem como histórico das decisões de arquitetura, evitando perda de contexto e facilitando a evolução do projeto.

## Convenção

- ADR-0001
- ADR-0002
- ADR-0003
- ...

Uma ADR nunca deve ser modificada para representar uma decisão diferente. Caso a arquitetura evolua, uma nova ADR deve ser criada referenciando a anterior.
